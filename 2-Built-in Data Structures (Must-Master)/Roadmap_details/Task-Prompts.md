# Dictionaries — Task Prompts

## Task: Pop and Len

**Dict banao** `"fruit"` se fruits ki prices ke saath (3 items). Phir:

1. Ek item `pop()` se hatao — value variable mein store karo aur print karo.
2. Ek nonexistent key ko `pop()` se hatao with default `"not found"` aur usse bhi print karo.
3. `len()` print karo kitni items bachi hain.

Run karo, output mujhe batao.

## Task: Update and Setdefault

1. Do dict banao — `a` (2 items) aur `b` (2 items), kam az kam ek key dono mein common rakho.
2. `a.update(b)` karo aur `a` print karo — common key ki value ka kya hua?
3. Ek dict `user` banao jisme `"name"` existing ho.
4. `setdefault("name", "Unknown")` karo — print karo, dekho value badli ya nahi.
5. `setdefault("age", 25)` karo — print karo, aur `user` bhi print karo.
6. `setdefault("age", 30)` dobara karo — kya hua, aur kyun?

Run karo, output mujhe batao.
